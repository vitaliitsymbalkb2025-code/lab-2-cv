# CV у React

React-версія резюме Цимбала Віталія Юрійовича, створена на Vite.

## Запуск

```bash
npm install
npm run dev
```

## Перевірка

```bash
npm run lint
npm run build
```

## Компоненти

- `Header` — ім’я, роль і контактні дані.
- `Profile` — короткий професійний опис.
- `Experience` — досвід роботи.
- `Education` — освіта.
- `Skills` — групи технічних і soft skills.
- `Footer` — нижня частина сторінки.
